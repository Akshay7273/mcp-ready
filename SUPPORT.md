# Support

## Questions and migration help

Use [GitHub Discussions](https://github.com/Akshay7273/mcp-ready/discussions) for usage questions,
MCP migration discussions, and ideas that are not yet actionable bug reports.

## Bugs and false positives

Open an issue and include:

- the `mcp-ready` version and command used;
- the rule ID and reported file/line;
- a minimal source example or public reproduction repository;
- the expected behavior;
- terminal output or JSON report, with secrets removed.

False-positive reports are treated as product-quality work, not user error. A migration scanner
is only valuable when maintainers can trust its findings.

## Security reports

Do not open a public issue for vulnerabilities. Follow [SECURITY.md](SECURITY.md) instead.

## MCP specification questions

This project explains migration findings but does not define the protocol. For authoritative
protocol interpretation, use the [official MCP documentation](https://modelcontextprotocol.io/)
and specification repository.
